# Artist archive prototype

A prototype that turns an unstructured artist CV into a structured, browsable digital archive. Paste in CV lines like "2019, Residency at Villa Medici, Rome" and get a searchable catalogue, a timeline view, and a page per entry, all generated from AI-structured data.

Built with Next.js (App Router), TypeScript, Zod, the Gemini API and the Pexels API. Both have free tiers.

## How it works

Raw CV text goes to Gemini with a fixed response schema. Gemini returns one JSON record per line: year, type, title, institution, city, country, description, tags, and a short image search query. Zod validates every record, then plain code adds a URL id, fetches a contextual image from Pexels using the AI's query, and flags any record the AI itself wasn't confident about.

The result is committed as `data/experiences.json` and the site is built from that file. The archive, timeline and detail pages need no API key at runtime, they just read the JSON.

The one exception is `/playground`, which calls Gemini live so visitors can paste their own CV lines and watch the extraction happen. That route needs `GEMINI_API_KEY` set as an environment variable wherever it's deployed. Nothing typed there gets saved, it's a live demo only, this site has no database.

## Data model

- `year, type, title, institution, city`: read straight from the line
- `country, description`: filled in by the AI when not explicit (country from a known city, a short neutral summary)
- `tags, imageQuery`: generated by the AI, used for filtering and for the image search
- `sourceText`: the original line, kept verbatim so every record traces back
- `confidence`: high, medium or low, set by the AI
- `needsReview`: true only when confidence isn't high, the one actionable flag
- `id, images`: added by code after the AI call, not by the AI itself

## Pages

- `/` artist profile, stats, links into the archive and the playground
- `/archive` the catalogue, filterable by type and country, grid or timeline view
- `/archive/[slug]` one entry, with the source line and the full JSON record
- `/playground` paste CV lines, get structured output live
- `/method` how the pipeline works

## Run it

```bash
npm install
cp .env.example .env.local     # add GEMINI_API_KEY and PEXELS_API_KEY
npm run extract                # reads data/raw-cv.txt, writes data/experiences.json
npm run dev
```

```bash
npm run extract -- --skip-images       # no Pexels lookup
npm run extract -- path/to/full-cv.txt # a different CV file
```

## Deploy

Push to GitHub, import the repo in Vercel. In the project's environment variables, add `GEMINI_API_KEY` so `/playground` works. `PEXELS_API_KEY` and `GEMINI_MODEL` are optional there, they're only used by the `npm run extract` script, not at runtime.
